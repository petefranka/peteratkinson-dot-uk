# Remote Work: Communication Is Everything

Working remotely has taught me that communication isn't just about what you say. It's about when, how, and why you say it.

## Default to Async, But Know When to Sync

Not everything needs a meeting. Most things can be handled asynchronously:

- **Documentation** - Write it down, share it, let people read it when they have time
- **Code reviews** - Async reviews with clear feedback
- **Status updates** - Use tools like Slack threads or project boards

But some things need real-time conversation:

- **Complex problem solving** - When you need to think through something together
- **Relationship building** - Regular 1:1s and team social time
- **Urgent issues** - When something is blocking and needs immediate attention

## Over-communicate, Especially Context

In an office, you pick up context from overheard conversations and body language. Remote, you need to be explicit:

- **Why** you're making a decision, not just what
- **What** you tried before asking for help
- **When** you'll be available or away
- **How** you prefer to be contacted for different types of issues

## Write Better Messages

Good async communication is a skill:

- **Subject lines matter** - Make them descriptive
- **Lead with the ask** - Put what you need at the top
- **Provide context** - Link to relevant docs, PRs, or conversations
- **Set expectations** - "No rush" vs "Need by EOD"

## The Tools Don't Matter

Slack, Teams, Discord, email. They're all fine. What matters is:

- **Consistency** - Use the same channels for the same things
- **Clarity** - Make it easy to find information later
- **Culture** - Respect people's time and boundaries

## Conclusion

Remote work amplifies communication problems. But it also gives you the opportunity to be more intentional about how you communicate. Use it.
